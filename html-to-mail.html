API configuration

One-time Google setup

  1. Open Google Cloud Console → enable the Gmail API for your project.
  2. Under Credentials, use an OAuth client ID of type Web application.
  3. Add this page's origin to Authorized JavaScript origins:
    -
  4. On the OAuth consent screen, add your Gmail address as a test user (while in Testing mode).
  5. Come back here and press Connect Gmail.
Google sign-in does not work from a file:// page. Host this file on https:// or run python3 -m http.server and open http://localhost:8000.
Client secret is not used. Browser sign-in uses Google Identity Services, which needs only the Client ID. A secret placed in a web page is public, so keep it out of this file, and rotate it if it was ever shared.
