API credentials

The OAuth client secret is intentionally not used here. Browser sign-in (Google Identity Services) never needs it, and a secret placed in front-end code is public to anyone who opens the file.

Setup checklist

  1. Enable the Gmail API in your Google Cloud project.
  2. Under OAuth consent screen, add your Gmail address as a test user while the app is in testing.
  3. In the OAuth client (Web application), add this exact origin to Authorized JavaScript origins:
  4. Serve this file over https:// or http://localhost. Google sign-in does not work from file://.
  5. Come back, press Connect Gmail, and approve the permission.
